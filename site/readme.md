# Spline

Spline provides a reusable spline engine for .NET together with an Avalonia
desktop application used to explore, validate, and tune curve behavior.

## What is included

- `Spline.Core` for reusable spline geometry, Bezier path generation, curve-grid
  interpolation, curvature helpers, and headless polyline simplification.
- `DemoSpline` for interactive editing and visualization of spline behavior in
  an Avalonia desktop application.
- GitHub Actions workflows for CI, package publishing, release automation, and
  documentation deployment.

## Packages

| Package | Description |
| --- | --- |
| `Spline.Core` | Reusable spline geometry and fitting primitives intended for NuGet distribution. |
